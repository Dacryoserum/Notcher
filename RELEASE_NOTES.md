## Notcher 1.3.0

- **Mode développeur** : un interrupteur dans Réglages → Services regroupe tout ce qui concerne les agents IA (onglet Agents, quotas, connexions Claude Code et Codex). Désactivé, rien de tout cela n'apparaît.
- **Permissions depuis le notch** : quand Claude Code ou Codex demande l'autorisation d'utiliser un outil, la question s'affiche sous le notch avec Autoriser et Refuser. Pour Codex, approuve une fois le hook avec `/hooks`.
- **Sous-agents** : l'onglet Agents montre les sessions en cours, celles qui t'attendent et les sous-agents au travail.
- **Notch musique plus compact** : la pochette à gauche, des barres à sa couleur à droite, plus de minuteur. Survole les barres pour mettre en pause ou relancer sans ouvrir le panneau. Changer le volume pendant la lecture l'affiche à droite des barres.
- **Apple Music** : la pochette s'affiche (macOS demande une fois l'autorisation de contrôler Music).
- **Widget musique** : dès qu'il est assez grand, la pochette occupe sa hauteur, entourée d'un halo à sa couleur.
- **Widget horloge** : de grands chiffres élancés sur toute la hauteur, trois styles au choix dans Réglages → Widgets.
- **Mode Discret** : le notch fermé reste vraiment nu, seule une demande de permission le réveille.
- **Le titre du morceau** ne s'affiche plus dans le notch quand la chanson change.
- **Corrections** : le prompteur pouvait rendre tout le panneau insensible aux clics ; les quotas de Claude Code cessaient d'arriver après un déplacement de l'app ; le bouton d'actualisation des quotas dit maintenant ce qu'il a fait.
- **Installation** : Notcher est aussi distribué en image disque (.dmg).
