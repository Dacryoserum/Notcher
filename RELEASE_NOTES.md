## Notcher 1.2.0

- **Mise à jour automatique** : Notcher cherche les nouvelles versions une fois par jour et les installe d'un clic (point vert dans le panneau, puis Réglages). Cette version s'installe encore à la main ; les suivantes arriveront toutes seules.
- **Notch vivant** : au repos le notch reste nu. Il s'anime quand Claude Code commence à répondre, attend une permission ou a terminé, quand un téléchargement se termine, avant un rendez-vous, quand la batterie est faible ou que le mode éveillé est actif.
- **Date et heure** : désactivées par défaut dans le notch fermé, toujours disponibles dans Réglages → Apparence.
- **Corrections** : fuite de descripteurs de fichiers, minuteurs inutiles du Pomodoro et du prompteur.
